# 狼煙屋キャラクター紹介ページ

## 概要
狼煙屋（ノロシヤ）5体のキャラクター詳細を管理・表示するシステムです。  
フロントエンドから直接編集可能で、将来的にはSupabaseと連携してデータベース管理を行います。

## ファイル構成
- `index.html` - メインページ
- `characters.js` - キャラクターデータとロジック（ローカルストレージ版）
- `supabase-integration.js` - Supabase連携用（要設定）
- `supabase-setup.sql` - データベーステーブル作成用SQL

## 機能
- キャラクター一覧表示
- 詳細情報の閲覧（モーダル表示）
- キャラクター情報の編集
- 新規キャラクターの追加
- ローカルストレージでのデータ保存

## キャラクター一覧
1. **ピヨマル** - 好奇心旺盛でピュアタイプ（スズメ）
2. **フクロウジ** - 心配性の少しオタクタイプ（フクロウ）
3. **カラスケ** - ちょっとめんどくさいけど愛着の湧くタイプ（カラス）
4. **ハトポッポ** - のんびり屋でマイペースタイプ（ハト）
5. **ツバクロウ** - スピード重視のせっかちタイプ（ツバメ）

## Supabase連携設定
1. [Supabase](https://supabase.com)でプロジェクトを作成
2. `supabase-setup.sql`のSQLを実行してテーブルを作成
3. `supabase-integration.js`の以下の値を置き換え：
   - `SUPABASE_URL`: プロジェクトのURL
   - `SUPABASE_ANON_KEY`: プロジェクトのAPIキー
4. `index.html`に以下を追加：
   ```html
   <script src="https://cdn.jsdelivr.net/npm/@supabase/supabase-js@2"></script>
   <script src="supabase-integration.js"></script>
   ```

## 使用方法
1. ブラウザで`index.html`を開く
2. キャラクターカードをクリックして詳細を表示
3. 「編集」ボタンで情報を更新
4. 「新しいキャラクターを追加」で新規作成
