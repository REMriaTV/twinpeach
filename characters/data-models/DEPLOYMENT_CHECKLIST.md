# 狼煙屋データベース デプロイチェックリスト

## 🚀 デプロイ前の必須確認事項

### 1. データ構造の確認
- [ ] Supabaseのテーブル構造と一致しているか確認
  - `supabase-schema.sql`を参照
  - フラット構造を維持（ネストなし）
- [ ] 新しいフィールドを追加した場合、Supabaseに反映済みか

### 2. ローカルテスト
- [ ] ローカルサーバーで動作確認
  ```bash
  python3 -m http.server 8000
  ```
- [ ] Supabase接続テスト
- [ ] データ保存・読み込みテスト

### 3. キャッシュ対策
- [ ] JSファイルにバージョンパラメータ追加
- [ ] 重要な変更の場合、ファイル名自体を変更検討

### 4. デプロイ手順
```bash
# 1. 変更をコミット
git add .
git commit -m "変更内容を明確に記載"

# 2. GitHubにプッシュ
git push

# 3. GitHub Actionsの完了を確認
# https://github.com/REMriaTV/twinpeach/actions
```

### 5. デプロイ後の確認
- [ ] 5-10分待機（GitHub Pages反映時間）
- [ ] プライベートブラウジングで動作確認
- [ ] 通常ブラウザでキャッシュクリア後確認

## ⚠️ トラブルシューティング

### キャッシュ問題が発生した場合
1. **Safari**: 設定 → プライバシー → Webサイトデータを管理 → github.io削除
2. **Chrome**: 設定 → プライバシーとセキュリティ → 閲覧履歴データの削除
3. **開発者向け**: F12 → ネットワーク → Disable cache

### Supabaseエラーが発生した場合
1. エラーメッセージを確認（特にカラム名）
2. `supabase-schema.sql`と照合
3. データ構造がフラットか確認（ネストNG）
