## 現在のデータベース構造

### noroshiya_characters テーブル
```sql
- id: VARCHAR(50) PRIMARY KEY -- noroshiya_001形式
- color_name: VARCHAR(100) -- 灰汁色、樺茶色など
- color_code: VARCHAR(10) -- #9e9478など
- pattern_type: VARCHAR(50) -- 無地、縞々など
- personality: TEXT
- speech_style: TEXT
- favorite_topics: TEXT[] -- 配列
- message_types: TEXT[] -- 配列
- emotional_range: TEXT
- dialogues: JSONB -- セリフのJSON
- stone_color_affinities: TEXT[] -- 好む石の色
- matching_keywords: TEXT[]
- affinity_notes: TEXT
- backstory: TEXT
```

### birds テーブル
```sql
- id: VARCHAR(50) PRIMARY KEY -- bird_001形式
- name: VARCHAR(100)
- scientific_name: VARCHAR(200)
- size: VARCHAR(50)
- habitat: VARCHAR(200)
- characteristics: TEXT
- behavior: TEXT
- call_description: TEXT
- symbolism: TEXT
- season: VARCHAR(100)
- rarity: VARCHAR(50)
- image_url: TEXT
```

### stones テーブル
```sql
- id: VARCHAR(50) PRIMARY KEY -- stone_001形式
- name: VARCHAR(100)
- type: VARCHAR(100)
- colors: JSONB -- {"primary": "赤い", "secondary": "茶色い", "pattern": "縞模様"}
- hardness: NUMERIC(3,1)
- size_range: VARCHAR(100)
- texture: VARCHAR(100)
- transparency: VARCHAR(50)
- special_features: TEXT
- found_locations: TEXT
- rarity: VARCHAR(50)
- is_hiuchiishi: BOOLEAN -- 火打石として使えるか
- ng_keywords: TEXT[] -- NGキーワード配列
- image_url: TEXT
```

## 現在のフォーム構造

### 共通項目（全タブ）
1. **ID** - 読み取り専用、自動採番
2. **名前** - 必須項目

### 石タブのフォーム項目
1. 基本情報
   - ID（自動）
   - 石の名前
   - 石の種類
   - 火打石として使える（はい/いいえ）

2. 色の設定
   - 主な色（セレクトボックス）
   - 副次的な色（セレクトボックス）
   - 模様（テキスト）

3. 物理的特性
   - 硬度（モース硬度1-10）
   - 大きさの範囲
   - 質感（セレクトボックス）
   - 透明度（セレクトボックス）

4. その他の情報
   - 特別な特徴（テキストエリア）
   - 見つかる場所
   - レア度（セレクトボックス）
   - NGキーワード（カンマ区切り）

### 鳥タブのフォーム項目
1. 基本情報
   - ID（自動）
   - 鳥の名前
   - 学名
   - 大きさ

2. 生態情報
   - 生息地
   - 特徴（テキストエリア）
   - 行動（テキストエリア）
   - 鳴き声

3. その他
   - 象徴・意味
   - 季節
   - レア度（セレクトボックス）

### 狼煙屋タブのフォーム項目
1. 基本情報
   - ID（自動）
   - 色の名前
   - 色コード（カラーピッカー連動）
   - 模様（セレクトボックス）

2. 石の好み
   - 好む石の色（10色のチェックボックス）
   - 石の好みの理由（テキストエリア）

3. 性格・特徴
   - 性格（テキストエリア）
   - 話し方（テキストエリア）
   - 好きな話題（カンマ区切り）
   - 感情の幅

4. セリフ設定
   - 初回出会い時のセリフ
   - 再会時のセリフ
   - メッセージ送信時のセリフ
   - 返信受信時のセリフ

5. その他
   - マッチングキーワード（カンマ区切り）
   - 裏設定・バックストーリー（テキストエリア）
